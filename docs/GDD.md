# Mechanica — implementation contract

Twelve levels / four chapters retain the names and mechanisms in the master prompt. Each room has an engineer's record to inspect, which reveals physical rules and unlocks machine operation. A close-up is a rendered assembly, with real stateful controls and gauges, not a background hotspot puzzle.

Flow: home → chapter → level → room discovery → machine → solve → animated door → result → next. Final level energizes the four systems and reveals the machine is a seed archive, preserving life rather than a weapon.

Actions are validated against data guards; operations mutate a copy; systems update; objective evaluates; events are emitted. Simulation ticks are explicit and separate from visual time. Invalid actions report why. Undo retains penalty counters; reset restores a recoverable initial state. Hints escalate and never guess an action from an incompatible trace state.

Ratings baseline: three stars within target moves and no hints/failures, two within twice target and up to two hints, otherwise one. Completion always unlocks the next level. These are authored baselines, not claimed optimal solutions or user-tested difficulty.

# Điểm bắt đầu

Đây là source project Mechanica đã triển khai, phiên bản 1.1.0+2.

- Đọc [README](README.md) để cài đặt, chạy, build và xem screenshot.
- Đọc [hướng dẫn phát triển](docs/DEV_GUIDE.md) để dùng Developer Mode.
- Đọc [kiểm thử](docs/TESTING.md) và [bàn giao cuối](docs/RELEASE_HANDOVER.md) để đối chiếu kết quả thật.

`MECHANICA_MASTER_PROMPT_CODEX.md`, GDD, Art Bible và các báo cáo Phase 1/2 được giữ để tra cứu lịch sử thiết kế. `references/` và bản trích `reference_workflow.txt` là tư liệu local, chưa xác minh quyền phân phối và được loại khỏi GitHub/APK.
